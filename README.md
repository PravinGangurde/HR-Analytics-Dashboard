# HR Analytics Dashboard

## 📊 Project Overview
The **HR Analytics Dashboard** provides data-driven insights into workforce trends to help HR teams make informed decisions.  
It focuses on key metrics such as employee headcount, attrition, hiring trends, demographics, and performance to improve organizational efficiency and employee retention.

---

## 🎯 Objectives
- Analyze employee attrition patterns  
- Understand workforce demographics  
- Monitor hiring and turnover trends  
- Support HR decision-making with interactive visuals  
- Identify high-risk attrition segments  

---

## 🚀 Key Features
✔ Interactive dashboard with drill-downs  
✔ Attrition insights by department, role & demographics  
✔ Hiring vs Attrition trend analysis  
✔ Workforce diversity analytics  
✔ Salary & performance distributions  
✔ Filters for segmentation  

---

## 📌 Key Metrics Tracked
- Total Employees
- Attrition Count & Rate
- Average Age
- Average Salary
- Gender Ratio
- Hiring Trend
- Department-wise Headcount
- Job Role Distribution
- Education Level Distribution
- Age Group Analysis
